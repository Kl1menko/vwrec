# Project Overview — VW Recruit

## Project Name
VW Recruit

## Project Type
B2B recruitment website focused on international hiring for business clients.

## Primary Goal
Generate qualified B2B leads from employers who need staff for production, logistics, construction, hospitality, and operational roles.

## Secondary Goal
Educate users about the financial and operational benefits of international hiring versus local hiring.

## Core Offer
Reduce staffing costs and close labor shortages through international recruitment from Asia and Africa with full legal and operational support.

## Brand Inputs
- Name: VW Recruit
- Logo: use the version with airplane symbol
- Visual direction: clean white background, dark and gray text, orange CTA accents based on logo color
- Tone: reliable, modern, B2B, practical, conversion-oriented

## Core Audience
### Primary
- business owners
- operations managers
- HR directors
- factory managers
- logistics companies
- construction companies
- hotel / service operators

### Geography / Languages
Website must support:
- Ukrainian
- English
- Czech
- Polish
- Slovak
- German
- Lithuanian
- Estonian
- Hungarian
- Croatian
- Romanian
- Bulgarian

## Technical Direction
Build without Next.js.
Recommended implementation:
- Vite
- HTML
- CSS / SCSS
- Vanilla JavaScript
- modular architecture
- multilingual-ready structure
- SEO-friendly multi-page approach

## Main Functional Requirements
- multilingual website
- responsive layout with strong mobile priority
- lead form
- callback form
- step-by-step quiz
- Google email / Google workflow form submission
- case pages on separate URLs
- gated PDF report download via form
- popup video player
- timed / scroll-based popups
- light animations
- Google Analytics integration
- Meta / Facebook Pixel integration

## Recommended Site Model
SEO-oriented multi-page website with additional internal pages for:
- services
- industries
- case studies
- FAQ topics
- legal pages
- downloadable report landing page

## Success Criteria
- clear offer above the fold
- strong mobile UX
- visible CTA on every key screen
- simple and friction-light lead capture
- scalable multilingual structure
- SEO-ready page system
- reusable frontend architecture
