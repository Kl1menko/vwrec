# Design Brief — VW Recruit

## Goal
Create a clean, trustworthy, conversion-focused B2B recruitment website for VW Recruit.
The website must communicate speed, reliability, legal safety, and measurable business value.

## Brand Character
- professional
- efficient
- modern
- structured
- international
- trustworthy
- not overly corporate or cold

## Visual Style
- white primary background
- dark / black headings
- gray supporting text
- orange accent for CTA, highlights, key metrics, important conversion points
- palette should be derived from the provided logo
- overall feeling: premium simplicity with high readability

## UI Direction
- strong spacing
- clear hierarchy
- high contrast CTA
- minimal visual noise
- business-first design
- mobile-first execution
- visual trust markers early on

## Main UX Priorities
1. Immediately explain what VW Recruit does
2. Show business benefit in numbers
3. Lead the user to calculation / quiz / consultation request
4. Build trust with cases, process, guarantees, and legal support
5. Keep interaction easy on mobile devices
